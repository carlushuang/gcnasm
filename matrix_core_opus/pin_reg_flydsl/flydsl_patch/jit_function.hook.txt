FlyDSL source changes (python/flydsl/compiler/):

1) Add pin_mfma.py (this dir): pin_all_mfma_agpr() wraps rocdl.mfma A/B with
   llvm.amdgcn.pin.agpr; codegen_via_llc() codegens the device module with
   llc+lld (which honors the pin, unlike the in-process serializer).

2) In jit_function.py, MlirCompiler.compile(), dump-mode fragment loop, replace:

       if frag.strip().startswith("gpu-module-to-binary"):
           llir = _extract_llvm_ir(module)

   with:

       if frag.strip().startswith("gpu-module-to-binary"):
           if os.environ.get("FLYDSL_PIN_MFMA_AGPR"):
               from .pin_mfma import pin_all_mfma_agpr
               _npin = pin_all_mfma_agpr(module)
               print(f"[flydsl.compile] pinned {_npin} rocdl.mfma A/B -> AGPR")
           llir = _extract_llvm_ir(module)
           if os.environ.get("FLYDSL_PIN_CODEGEN_LLC"):
               from .pin_mfma import codegen_via_llc
               codegen_via_llc(module, llir)
               _sn = f"{stage_num_base + idx:02d}_{_stage_label_from_fragment(frag)}_llc"
               _o = _dump_ir(_sn, dump_dir=dump_dir, asm=module.operation.get_asm(enable_debug_info=True))
               print(f"[flydsl.compile] dump {_sn} (llc codegen) -> {_o}")
               continue

Enable at runtime:
   FLYDSL_DUMP_IR=1 FLYDSL_PIN_MFMA_AGPR=1 FLYDSL_PIN_CODEGEN_LLC=1 \
   FLYDSL_PATCHED_LLC=<flydsl-llvm build>/bin/llc  python kernel.py
